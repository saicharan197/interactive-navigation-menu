# 🚀 Responsive Landing Page

A modern, responsive landing page built using **HTML, CSS, and JavaScript**. This project features an interactive navigation bar that changes its appearance when scrolling and hovering over menu items.

## ✨ Features

* 📌 Fixed navigation bar that stays visible while scrolling.
* 🎨 Interactive hover effects with smooth animations.
* 🌈 Dynamic navbar styling based on scroll position.
* 📱 Fully responsive design for mobile, tablet, and desktop.
* 🍔 Mobile-friendly hamburger navigation menu.
* 🔗 Smooth scrolling between page sections.
* 💡 Active navigation link highlighting.
* 🃏 Modern service and project cards with hover effects.
* 📩 Contact form with client-side validation.
* ⚡ Scroll-reveal animations using the Intersection Observer API.

## 🛠️ Technologies Used

* **HTML5** — Website structure.
* **CSS3** — Styling, animations, and responsive layouts.
* **JavaScript** — Interactive navigation and dynamic functionality.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/interactive-navigation-menu.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Alternatively, use the **Live Server** extension in VS Code.

## 🎯 Objective

The objective of this project is to create a responsive landing page with an interactive navigation menu that changes color or style when the user scrolls or hovers over navigation items.

This project was developed as part of **Task 01 — Responsive Landing Page**.
